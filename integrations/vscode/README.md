# D2 MCP Server

This companion extension registers the D2 MCP Server with compatible VS Code and Code OSS clients. It runs the published container with Docker and confines file access to the active workspace folder.

Docker must be installed and available to the extension host. The server image and extension use the same release version.

Source, security details, and usage documentation are available at [github.com/RecursiveFunctions/d2mcp](https://github.com/RecursiveFunctions/d2mcp).
